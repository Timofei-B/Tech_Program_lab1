# Лабораторная работа 1: скрипт собирающий параметры текущей ОС

Простой сборщик информации об операционной системе на Python.
Собирает данные о системе, процессоре, Python-окружении и переменных
окружения, после чего сохраняет всё в JSON-файл.

Проект написан с использованием **только стандартных библиотек** Python,
поэтому не требует установки дополнительных пакетов.

---

## Описание работы

1. Скрипт запускается и собирает данные с помощью модулей `platform`, `os`, `socket` и `sys`.
2. Все данные складываются в словарь Python.
3. Словарь сохраняется в файл `os_info.json` с помощью модуля `json` в кодировке UTF-8 (с отступами и поддержкой русских букв).

Кроссплатформенность обеспечена за счёт оператора `or`:
для каждой ОС берётся первая доступная переменная окружения
(например, `SHELL` для Linux/macOS или `COMSPEC` для Windows).

## Параметры

### Общая информация о системе
| Параметр | Источник | Пример |
| --- | --- | --- |
| Имя компьютера | `socket.gethostname()` | `Desktop` |
| Операционная система | `platform.system()` | `Linux` / `Windows` / `MacOS` |
| Релиз ОС | `platform.release()` | `6.5.0-27-generic` |
| Версия ОС | `platform.version()` | `#28~22.04.3-Ubuntu` |
| Архитектура | `platform.machine()` | `x86_64` |
| Процессор | `platform.processor()` | `x86_64` |
| Платформа | `platform.platform()` | `Linux-6.5.0-...` |
| Количество ядер CPU | `os.cpu_count()` | `8` |
| Детали ОС | `platform.libc_ver()` / `win32_ver()` / `mac_ver()` | `['glibc', '2.35']` |

###  Пользователь и окружение
| Параметр | Источник | Пример |
| --- | --- | --- |
| Оболочка командной строки | `SHELL` (Linux/macOS) или `COMSPEC` (Windows) | `/bin/bash` |
| Имя пользователя | `USER` или `USERNAME` | `user` |
| Путь к домашней папке | `HOME` или `USERPROFILE` | `/home/user` |
| Текущая папка | `os.getcwd()` | `/home/user/project` |

###  Информация о Python
| Параметр | Источник | Пример |
| --- | --- | --- |
| Версия Python | `sys.version` | `3.11.5 (main, ...)` |
| Версия Python (кратко) | `platform.python_version()` | `3.11.5` |
| Компилятор Python | `platform.python_compiler()` | `GCC 11.4.0` |
| Реализация Python | `platform.python_implementation()` | `CPython` |
| Путь к Python | `sys.executable` | `/usr/bin/python3` |
